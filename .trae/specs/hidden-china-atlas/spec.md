# Hidden China Atlas - 产品需求文档

## 概述
- **摘要**：一个面向海外用户的互动网站，旨在展示中国不为人知的隐藏之美，帮助用户发现除北京、上海和热门景点外的独特目的地。
- **目的**：通过直观的地图交互、精选目的地展示和智能旅行规划工具，让海外用户轻松发现中国的隐藏宝藏。
- **目标用户**：对中国文化和自然景观感兴趣的海外旅行者，寻求独特、非大众旅游体验的游客。

## 目标
- 打造一个视觉吸引力强、交互流畅的中国隐藏目的地探索平台
- 提供直观的地图交互体验，让用户快速发现感兴趣的地点
- 通过精选内容和智能推荐，展示中国多样化的隐藏之美
- 支持双语切换，确保英文用户体验流畅自然
- 实现智能旅行规划功能，根据用户偏好推荐个性化目的地

## 非目标（超出范围）
- 不提供实时旅游预订功能
- 不包含详细的交通预订系统
- 不做复杂的 GIS 地图系统，优先考虑视觉体验和交互流畅度
- 不追求地理精度，重点是探索感和产品感
- 不是普通旅游信息页或百科全书

## 背景与上下文
- 海外用户对中国的了解往往局限于北京、上海等主要城市和热门景点
- 中国拥有丰富的自然景观、历史文化和独特的地方风情，许多值得探索的目的地尚未被国际游客广泛知晓
- 现有旅游资源多集中在热门景点，缺乏对隐藏宝藏的系统性展示

## 功能需求
- **FR-1**：首页 Hero 区，包含英文默认展示、中文切换、主标题、副标题和 CTA 按钮
- **FR-2**：中国互动地图，使用简化的 SVG 地图，展示目的地标记，点击后显示详情
- **FR-3**：Hidden Picks 精选目的地模块，展示 10-12 个隐藏宝藏地点，包含详细信息
- **FR-4**：筛选功能，支持按季节、氛围、旅行时长和人群水平进行过滤
- **FR-5**：简易 AI / Smart Trip Planner，根据用户输入推荐 2-3 个目的地和行程建议
- **FR-6**：双语切换功能，默认英文，提供中英切换按钮

## 非功能需求
- **NFR-1**：视觉设计要求高级、克制、现代、编辑感，参考 premium travel product + modern magazine + startup landing page 风格
- **NFR-2**：响应式设计，适配桌面和移动端
- **NFR-3**：交互流畅，包含轻微动画和悬浮反馈
- **NFR-4**：代码结构清晰，组件化设计，易于维护和扩展
- **NFR-5**：性能优化，确保页面加载速度快，交互响应及时

## 约束
- **技术**：使用 Next.js（App Router）、TypeScript、Tailwind CSS
- **数据**：使用本地 JSON / TS objects 作为数据源
- **地图**：优先使用本地 SVG / 简化交互实现，避免引入过重依赖
- **部署**：易于部署到 Vercel 或类似平台

## 假设
- 目标用户主要是英文使用者，对中国文化和旅行有兴趣
- 用户更关注目的地的独特性和体验，而非详细的交通预订
- 无需实时数据，使用静态数据即可满足 MVP 需求
- 未来可考虑接入真实 AI API 和动态数据源

## 验收标准

### AC-1：首页 Hero 区
- **Given**：用户访问网站首页
- **When**：页面加载完成
- **Then**：显示英文主标题、副标题和 CTA 按钮，提供中文切换选项
- **Verification**：`human-judgment`
- **Notes**：视觉效果要有高级感，文案自然流畅

### AC-2：中国互动地图
- **Given**：用户进入地图探索页面
- **When**：用户点击地图上的标记或区域
- **Then**：右侧/下方显示地点卡片或详情，交互流畅
- **Verification**：`human-judgment`
- **Notes**：地图视觉效果美观，交互响应及时

### AC-3：Hidden Picks 精选目的地
- **Given**：用户浏览精选目的地模块
- **When**：用户查看每个目的地
- **Then**：显示完整的目的地信息，包括中英文名称、所在省份、tagline、特色、最佳季节、理想旅行时长、氛围标签、人群水平和交通方式
- **Verification**：`programmatic`
- **Notes**：至少包含 10-12 个地点，分布覆盖不同区域

### AC-4：筛选功能
- **Given**：用户使用筛选功能
- **When**：用户选择筛选条件（季节、氛围、旅行时长、人群水平）
- **Then**：目的地列表根据筛选条件更新
- **Verification**：`programmatic`
- **Notes**：筛选逻辑正确，响应及时

### AC-5：Smart Trip Planner
- **Given**：用户使用旅行规划工具
- **When**：用户输入出发城市、天数、兴趣和是否避开人群
- **Then**：系统生成 2-3 个推荐目的地，包含推荐理由、建议季节、游玩时长和简单行程
- **Verification**：`human-judgment`
- **Notes**：推荐结果合理，界面友好

### AC-6：双语切换
- **Given**：用户使用语言切换功能
- **When**：用户点击语言切换按钮
- **Then**：网站内容在英文和中文之间切换，文案自然流畅
- **Verification**：`human-judgment`
- **Notes**：英文文案自然，中文文案简洁

### AC-7：响应式设计
- **Given**：用户在不同设备上访问网站
- **When**：用户调整屏幕尺寸或在移动设备上访问
- **Then**：网站布局和内容自适应，保持良好的用户体验
- **Verification**：`human-judgment`
- **Notes**：在桌面和移动设备上均能正常显示和交互
